<!-- 代码写法九条：不分语言的原则，各项目在 CLAUDE.md 的「## Code style」下用 @ 引入，不复制 -->

结构精炼，叙述自然，注释用中文。九条不分语言；某门语言的具体落法写在该语言的落法文件或项目语言目录的 CLAUDE.md，样板文件由项目在引入处写明。

1. 每个文件第一行用一句话写它是干什么的。
2. 主流程按编号步骤写注释（`1.`、`2.`、`2.1`），一个步骤可管几行，不逐行注释。
3. 进入分支或提前返回时，写一句「走到这里说明什么」（如 `走到这里说明缓存未命中`）。
4. 返回元组或特殊值时，docstring 写清每种情况的含义。
5. 不复述代码。一看就懂的行不写注释；行尾注释只写「为什么」，不写「做什么」。
6. 不留注释掉的代码和调试输出（`print`、`console.log`）。
7. 同一段逻辑出现第二次就抽成函数。
8. 兜底式错误处理并给降级结果（`except Exception`、`.catch(() => …)`、`catch(e){}`）只放在面向用户或命令行的最外层；内部函数让错误往上抛。
9. 不加当前没有调用方的参数、配置项、扩展点。

另外，所有语言：一行只做一件事；`a and b or c` 这类要停下来想优先级的表达式拆开写。
